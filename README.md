# 菊名桜山公園 / 協力金の行方

マートルコート菊名 管理組合・理事会・住民向けに作成したZINEシリーズのソースコードです。
セナリ学院ワークショップ「ひとつの素材からZINEとWebサイトを作る」の成果物。

---

## 概要

菊名桜山公園愛護会への年間3万円の協力金継続可否を検討するため、住民アンケート結果・理事会での議論・横浜市との協議経過をまとめたシリーズ資料。1冊あたりA4×6ページの固定レイアウトで、印刷・PDF配付とWeb閲覧の両方に対応。

## デザイン

- 固定A4サイズ（210mm × 293mm）の `<div>` ページ構成
- comomo デザインシステム準拠（ノーシャドウ・ノーグラデーション・1.5px ボーダー）
- カラーテーマ：桜ピンク / 薄緑 / 緑（公園テーマ）
- フォント：Hiragino Maru Gothic ProN / Noto Sans JP（本文）/ Oswald（数字・英字ラベル）/ Caveat（引用装飾）

詳細は `DESIGN.md` を参照。

## 閲覧・印刷方法

- **Web閲覧:** `index.html` を起点に各号のweb版へ。GitHub Pages でも公開。
- **印刷用PDF生成:** A4版HTMLをSafariで開く → ファイル > プリント > 「PDFとして保存」。
